# Python 环境管理

入口：侧栏「运行 → Python 环境」。环境记录独立保存在应用的 Application Support 目录下的 `python-environments.json`，不修改全局 PATH 或 Shell 配置。

## 使用

- **添加已有**：选择 `.venv` 等环境目录，并设置名称、工作目录和默认终端。支持标准 venv、virtualenv 和 uv 创建的虚拟环境；不支持 Conda。
- **发现环境**：选择项目根目录，扫描最多 5 层、4,000 个目录、20,000 个条目、100 个环境。跳过符号链接、依赖缓存和大多数隐藏目录；未找到的环境可手动添加。
- **新建环境**：选择本机 Python 3 可执行文件与尚不存在的目标路径，通过 `python -I -m venv` 创建。不会下载 Python 或覆盖已有路径。创建失败时保留目录并报告位置。
- **打开终端**：默认使用环境记录中的终端，也可通过下拉菜单单次选择内置终端或系统 Terminal.app。新会话进入工作目录并激活环境，保留交互式 Shell；支持 zsh / bash。Python 会话不加载个人 Shell 启动配置，避免其他环境的自动激活钩子覆盖选择。
- **复制激活命令**：按钮位于「运行脚本」旁，复制经过路径转义的 `source …/bin/activate`，可粘贴到其他 zsh / bash 会话。只激活环境，不改变当前目录，命令只影响执行它的会话。
- **运行脚本**：选择脚本，每行输入一个参数，无需手写 Shell 引号。使用环境中的 Python 绝对路径运行，结束后保留终端；分屏不会再次执行脚本。
- **已安装模块**：点击详情页中的入口打开二层窗口，查看包名和版本、搜索或刷新。使用 Python 3.8+ 的 `importlib.metadata` 读取分发包信息，不依赖 pip，不包含标准库。共享系统包的环境会显示其可见的共享包。
- **移除记录**：只移除登记信息，不删除环境、项目文件或依赖，也不关闭已打开的终端。

## 信任与边界

只添加自己信任的环境。扫描和结构校验不执行环境中的代码；版本检查和模块读取会运行所选环境的 Python（使用 `-I` 隔离项目目录、用户 site 和 Python 环境变量）。Python 启动仍可能执行该环境本身的 `.pth` 或 site 初始化代码；打开终端则会执行该环境的激活脚本。

内置终端在交互式 Shell 的启动文件中完成激活，不依赖延时后模拟输入。激活失败或激活脚本指向其他目录时终止该会话，避免悄悄使用系统 Python。系统终端使用独立的临时 `.command` 文档启动，启动文件读入后清理，不要求 Apple Events 自动化权限。

当前不包含 Conda 管理、依赖安装/升级/卸载、环境目录删除、运行中心任务绑定或环境记录的跨机备份。移动虚拟环境可能使激活脚本或包内可执行脚本失效，通常应重新创建环境，而非只修改登记路径。

# Xen 原生集成

## 入口与界面

Xen 集群位于「服务器」页面，不增加侧栏入口、二级菜单或全局功能开关。

- 页头「添加」菜单包含添加服务器、添加 Xen 集群和导入 SSH 配置。
- 没有集群时不显示空分区；首次添加入口也位于服务器空状态中。
- 添加表单的「添加并连接」先保存配置及 Keychain 凭据，再进入集群页面连接。单独保存配置的模型方法不会建立网络连接。
- 已保存集群使用独立的紧凑摘要分区，与 SSH 服务器共用字体、留白和图标语言。
- 集群内以概览、主机、虚拟机、存储、网络切换栏目；模板、快照、磁盘、任务、消息、补丁、用户、角色及告警位于「更多」。
- 资源清单使用原生 Table；虚拟机清单可按名称排序、多选、搜索，并显示状态、主机、vCPU、内存上限、来宾上报 IP。
- 详情使用稳定内容底色；Liquid Glass 用于导航与操作层。减少透明度或增强对比度时，导航背景回退为系统实色及边框。
- 控制台打开独立 AppKit 窗口。任务在底部按需出现，错误与未知结果保留可读说明。

启动时默认只读取配置，不连接 Xen。每个集群的高级选项可明确选择启动连接和断线重连，均默认关闭。重连最多连续尝试三次；写操作始终不重放。

## 架构

代码位于 `inchspace/Xen/`。通过 ContentView 持有 XenStore，切换应用侧栏时保留已建立的会话。SSH 的 Server、凭据与连接模型继续独立。

| 层 | 实现 |
| --- | --- |
| 界面 | SwiftUI 原生表格、表单、Picker、Sheet、系统按钮及 macOS 26 glassEffect；AppKit 控制台窗口 |
| XML-RPC | Foundation XMLParser 与类型化 XenValue；拒绝外部/内部实体、重复结构字段、无效布尔和整数、过深 XML 和过大响应 |
| 管理连接 | URLSession、逐连接 TLS 策略、窄签名登录回退、主节点重定向、会话和资源池身份检查 |
| 写操作 | 新鲜记录校验、UUID/连接代次匹配、资源预约、Task 终态和操作结果核对 |
| 凭据 | Security / Keychain，独立服务标识 `vip.lylab.inchspace.xen`；JSON 不保存密码或 session |
| 控制台 | Network.framework CONNECT/TLS + 原生 RFB 解码与 AppKit 画布，无 Electron、WebView、JavaScript 或 noVNC |
| XVA | FileHandle tar 元数据预览；URLSession 文件流；资源池主机白名单重定向；原 Task 恢复核对 |
| 监控 | RRD xport XML、精确 UUID 归属、Swift Charts、有界本地历史 |
| 通知 | HTTPS Webhook；Network.framework 隐式 TLS SMTP；默认关闭，密码存 Keychain |

没有新增第三方运行时或包依赖，没有提高项目最低系统版本。

## 继续保持关闭的操作

以下操作与参考项目的保护范围一致，菜单不可执行，服务层也拒绝调用：

- VM 迁移、存储移动、复制与跨池写操作。
- 主机维护、疏散与资源池加入/移除、治理。
- HA 写操作、补丁安装、RBAC 用户/认证/权限变更。
- SR 创建、销毁、连接生命周期与高级存储配置。
- PIF、Tunnel、VLAN、Bond 等物理网络拓扑变更。
- 批量删除 VM。

列表和详情可继续查看对应的只读信息。保护不会因隐藏或禁用某个按钮而成为唯一防线。

## 操作结果与恢复

- 写请求只有明确的 XAPI 失败响应才作为服务器拒绝；连接中断或响应无法解析时显示“结果未知”，不自动重发。
- 多个连接指向同一池时，界面服务按池 UUID 和资源 UUID 阻止重复操作。
- VM/设备创建后配置失败会保留对象，并告知已知引用，不自动清理结果不确定的磁盘或设备。
- XVA 使用原 Task 引用与资源池 UUID 写入恢复日志。重连只核对原 Task，不重新上传、下载或配置对象。
- 下载先写 `.partial`，HTTP 与 Task 均确认后才替换用户选择的目标文件。未知结果保留临时文件，已确认失败清理当前临时文件。
- 取消 XVA 同时停止本机传输并提交服务器 task.cancel；不把取消请求等同于服务器已停止。
- 运行 VM 的导出 checkpoint 会保留在快照列表中，用户可核对后删除。
- 普通任务历史当前保存在内存中；XVA 恢复记录、告警、监控历史单独持久化。

## 尚需实机验收与后续补齐

这次建立原生功能覆盖，不声明与参考项目逐方法、逐 UI 行为完全等价，也不声明服务器兼容认证。

- 缺少测试环境，真实服务器版本、TLS、RBAC、存储后端、Guest Tools 与 mutation 恢复矩阵均待验收。
- 当前 XVA 预览支持常规 tar 中的 XAPI XML-RPC `ova.xml`；简化 appliance 元数据、压缩 tar、GNU 长文件名等格式仍需扩展。导入后需检查网络，预览确认中可按源网卡选择目标网络，未选择的网卡保留服务器导入配置。
- 原生 RFB 目前不支持额外 VNC 密码认证、扩展剪贴板、完整输入法组合输入和压缩编码。raw 帧适合先做协议验收，大分辨率性能待实测。
- SMTP 采用隐式 TLS，尚不支持 STARTTLS 与 OAuth。外部通知按新事件发送，失败不会自动重复投递；邮件和 Webhook 独立投递并记录各自结果。
- vCPU 上限在关机时独立配置；池级入口提供逐 VM 启动延迟，不宣称存在 XAPI 未提供的严格启动依赖顺序。快照/模板删除只删除对象，不自动回收共享/所有权不确定的 VDI。
- 现有 inchspace 配置备份格式没有自动扩展到 Xen；Xen 配置独立保存在 Application Support，密码始终留在 Keychain。

## 自签名证书连接修复

2026-11-09：确认已保存的证书选项为开启，但 AsyncBytes 请求的任务级 server-trust 回调未被原实现处理。RPC 与监控请求现在显式使用任务代理，并在会话级和任务级挑战中复用逐连接信任策略；默认校验保持开启，不修改系统或其他连接信任。连接入口也从存储中解析最新配置，避免旧视图值覆盖已保存选项。

新增本地自签名 HTTPS 回归覆盖 RPC、监控及关闭/开启/再次关闭策略隔离；用真实管理端点进行了无凭据的只读诊断，开启后可通过 TLS 并收到 XAPI 会话错误响应，未读取或验证用户密码。
